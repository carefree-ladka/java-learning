# Modern Java 17 → 27 (Q293–306)

Recent LTS releases (17, 21, and 25) changed how backend Java is written.
Interviewers increasingly expect familiarity with virtual threads, records,
pattern matching, and — more recently — scoped values and the JDK 27 runtime
defaults. Java 25 is the current LTS; Java 27 is the latest feature release.

<ProgressTracker id="iq-modern-java" />

## Latest language features (293–306)

**293. What are virtual threads (Project Loom)?**
Lightweight JVM-managed threads (Java 21) scheduled onto a few OS carrier threads. A
blocked virtual thread parks and frees its carrier, so you can run millions. See
[Virtual Threads](/docs/concurrency/virtual-threads/).

**294. Performance benefits of virtual threads.**
They make the simple blocking thread-per-request model scale to very high concurrency for
I/O-bound work — reclaiming readability from async/reactive code without OS-thread limits.

**295. When NOT to use virtual threads?**
CPU-bound work (they add no compute — use a sized platform pool), and don't pool them or
wrap blocking I/O in `synchronized` (pinning). See [pinning](/docs/concurrency/virtual-threads/#pinning-the-main-pitfall).

**296. How to create virtual threads?**
`Thread.startVirtualThread(task)` or
`Executors.newVirtualThreadPerTaskExecutor()`; in Spring Boot 3.2+ set
`spring.threads.virtual.enabled=true`.

**297. What are record patterns?**
Deconstruct a record directly in `instanceof`/`switch`:
`if (obj instanceof Point(int x, int y))` binds `x` and `y` — great with sealed types.

**298. Pattern matching for switch (Java 21).**
`switch` on types with binding and guards:
`case Circle c when c.radius() > 10 -> ...`; exhaustive over sealed hierarchies. See
[pattern matching](/docs/java-8-plus/#pattern-matching--switch-expressions).

**299. `getFirst()` and `getLast()` in collections.**
Java 21 `SequencedCollection` methods for first/last access and `reversed()` — a uniform
API across `List`, `Deque`, and `LinkedHashSet`.

**300. What happened to string templates?**
Previewed in Java 21–22 (`STR."Hello \{name}"`), then **withdrawn** for a redesign —
they are _not_ available in JDK 23–27. Until a new proposal lands, use
`String.format`, `formatted`, or a `StringBuilder`. Mentioning that you know they
were pulled signals you follow the language closely.

**301. Sequenced collections.**
Java 21 interfaces (`SequencedCollection`/`SequencedMap`) giving a defined encounter order
with `getFirst`/`getLast`/`reversed`/`putFirst`.

**302. What are records? Use cases.**
Immutable data carriers that auto-generate constructor, accessors, `equals`/`hashCode`/
`toString`. Ideal for DTOs and value objects. See [Records](/docs/java-8-plus/#records).

**303. Text blocks — advantages.**
Multi-line string literals (`"""..."""`) — readable JSON/SQL/HTML without escaping and
concatenation.

**304. Switch expression improvements.**
Arrow `switch` returns a value, has no fall-through, supports multiple labels, and can be
exhaustive — safer than the old statement form. See [switch expressions](/docs/java-fundamentals/operators-and-control-flow/#switch-expressions).

**305. Sealed interfaces.**
`sealed interface ... permits ...` restricts implementers to a known set, enabling
exhaustive pattern-matching switches. See [sealed classes](/docs/java-8-plus/#sealed-classes).

**306. Pattern matching for `instanceof`.**
`if (o instanceof String s)` tests and binds in one step, removing the explicit cast. See
[pattern matching](/docs/java-8-plus/#pattern-matching--switch-expressions).

## Java 22 → 27 highlights

**What are unnamed variables and patterns (`_`)?**
Final in Java 22. Use `_` for a required-but-unused binding — an ignored catch
variable (`catch (IOException _)`) or an unused record component
(`case Point(int x, _)`). Removes "unused variable" noise and states intent.

**What is `ScopedValue` and why prefer it over `ThreadLocal`?**
Final in Java 25. An immutable value bound for the dynamic scope of a call and
safely visible to child tasks. Unlike `ThreadLocal`, it can't be mutated mid-scope
and is cheap to inherit across the millions of virtual threads a server may spawn.
See [scoped values](/docs/java-8-plus/#scoped-values--structured-concurrency).

**What are compact source files and instance `main` methods (Java 25)?**
A beginner-friendly on-ramp: a source file can skip the class/`public static` boilerplate
and declare `void main()` plus top-level members, with `IO.println(...)` for console I/O.

**Is structured concurrency available yet?**
Still a preview through JDK 27 (seventh preview, JEP 533). `StructuredTaskScope`
runs subtasks as one unit — if one fails the rest are cancelled. In JDK 27 `join()`
throws `ExecutionException`. Needs `--enable-preview`.

**Name a few JDK 27 changes that affect apps with no code change.**
Compact object headers on by default (96 → 64-bit headers, less heap), G1 as the
default GC even on 1-CPU/low-memory containers, post-quantum hybrid key exchange
in TLS 1.3 (`X25519MLKEM768` offered first), and JFR data redaction. See
[What's new in JDK 27](/docs/java-8-plus/#whats-new-in-jdk-27).

**What's the LTS/non-LTS cadence?**
A feature release every 6 months; an LTS every 2 years. LTS line so far:
17 → 21 → 25 → **29 (Sept 2027)**. Java 27 is a non-LTS feature release.
