## Java string essentials

```java
String s = "abc";
s.charAt(0);                 // 'a'
s.substring(1, 3);           // "bc"  [start, end)
s.toCharArray();             // ['a','b','c']
s.length();
Character.isLetterOrDigit(c);
Character.toLowerCase(c);
int[] freq = new int[26];    // lowercase-only frequency (fast, no map)
freq[c - 'a']++;             // map 'a'..'z' to 0..25
```

<Warning>
Strings are **immutable** — never build them with `+=` in a loop (O(n²)). Use
`StringBuilder`. Compare with `.equals()`, never `==`. See
[Strings & the String Pool](/docs/java-fundamentals/strings/).
</Warning>

## Two pointers: palindromes

### Valid Palindrome — [LeetCode 125](https://leetcode.com/problems/valid-palindrome/)

```java
// OPTIMAL — O(n) time, O(1) space: skip non-alphanumerics, compare inward
boolean isPalindrome(String s) {
    int l = 0, r = s.length() - 1;
    while (l < r) {
        while (l < r && !Character.isLetterOrDigit(s.charAt(l))) l++;
        while (l < r && !Character.isLetterOrDigit(s.charAt(r))) r--;
        if (Character.toLowerCase(s.charAt(l++)) != Character.toLowerCase(s.charAt(r--)))
            return false;
    }
    return true;
}
```

### Longest palindromic substring — [LeetCode 5](https://leetcode.com/problems/longest-palindromic-substring/)

```java
// OPTIMAL (expand around center) — O(n^2) time, O(1) space
String longestPalindrome(String s) {
    int start = 0, end = 0;
    for (int i = 0; i < s.length(); i++) {
        int len = Math.max(expand(s, i, i), expand(s, i, i + 1)); // odd, even
        if (len > end - start) { start = i - (len - 1) / 2; end = i + len / 2; }
    }
    return s.substring(start, end + 1);
}
int expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
    return r - l - 1;
}
```

## Hashing: anagrams

### Valid Anagram — [LeetCode 242](https://leetcode.com/problems/valid-anagram/)

```java
// OPTIMAL — O(n): count with a 26-int array
boolean isAnagram(String s, String t) {
    if (s.length() != t.length()) return false;
    int[] c = new int[26];
    for (int i = 0; i < s.length(); i++) { c[s.charAt(i) - 'a']++; c[t.charAt(i) - 'a']--; }
    for (int x : c) if (x != 0) return false;
    return true;
}
```

### Group Anagrams — [LeetCode 49](https://leetcode.com/problems/group-anagrams/)

```java
// OPTIMAL — O(n * k log k): sorted string is the canonical group key
List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> groups = new HashMap<>();
    for (String s : strs) {
        char[] c = s.toCharArray();
        Arrays.sort(c);
        String key = new String(c);            // anagrams share this key
        groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(groups.values());
}
```

<Tip>
Two strings are anagrams iff their sorted form (or 26-length frequency signature) is
equal. Use the sorted string as a map key to group them.
</Tip>

## Sliding window: substrings

### Find All Anagrams in a String — [LeetCode 438](https://leetcode.com/problems/find-all-anagrams-in-a-string/)

```java
// OPTIMAL — O(n): fixed window of size p.length(), compare frequency arrays
List<Integer> findAnagrams(String s, String p) {
    List<Integer> res = new ArrayList<>();
    if (s.length() < p.length()) return res;
    int[] need = new int[26], win = new int[26];
    for (char c : p.toCharArray()) need[c - 'a']++;
    for (int i = 0; i < s.length(); i++) {
        win[s.charAt(i) - 'a']++;                       // add right
        if (i >= p.length()) win[s.charAt(i - p.length()) - 'a']--;  // drop left
        if (i >= p.length() - 1 && Arrays.equals(win, need)) res.add(i - p.length() + 1);
    }
    return res;
}
```

### Minimum Window Substring — [LeetCode 76](https://leetcode.com/problems/minimum-window-substring/)

```java
// OPTIMAL — O(n): grow to satisfy all needed chars, then shrink to minimize
String minWindow(String s, String t) {
    int[] need = new int[128];
    for (char c : t.toCharArray()) need[c]++;
    int required = t.length(), left = 0, bestLen = Integer.MAX_VALUE, bestL = 0;
    for (int right = 0; right < s.length(); right++) {
        if (need[s.charAt(right)]-- > 0) required--;    // consumed a needed char
        while (required == 0) {                          // valid window; try to shrink
            if (right - left + 1 < bestLen) { bestLen = right - left + 1; bestL = left; }
            if (need[s.charAt(left)]++ == 0) required++; // about to lose a needed char
            left++;
        }
    }
    return bestLen == Integer.MAX_VALUE ? "" : s.substring(bestL, bestL + bestLen);
}
```

## Things You Should Know

### 🔴 Must Know
- `int[26]`/`int[128]` frequency arrays; `StringBuilder` for building.
- Two pointers for palindromes; sliding window for substrings.
- Sorted string / frequency signature for anagrams.

### 🟡 Good to Know
- Expand-around-center for palindromic substrings.
- `Arrays.equals` to compare window vs need.

### 🟢 Nice to Know
- KMP / Rabin-Karp for pattern matching; rolling hashes.
